再生回数・コメント数は YouTube Data API v3 から取得した、取得時点の公式数値です。
今日のベスト3（赤）＝その日いちばん伸びている動画です。エンタメ・ニュース・音楽・お金は公開__T_HOT__日以内を優先し、足りない日だけ__C_HOT__日まで広げます。ほかのジャンルは公開__T_NORM__日以内を優先し、足りない日だけ__C_NORM__日まで。同じ動画がベスト3に居られるのは__STREAK__日連続までで、次の日からは4位以下に下げます。4位以下は、旬のジャンルが直近__HOT_FILL__日・ほかは直近__FILL__日の動画から埋めます。その日に実際に使った条件は各タブに表示します。総合は当日の急上昇そのものです。
殿堂入り（金）＝公開日を問わない歴代の再生回数順です。1日__HOF_PER_RUN__ジャンルずつ順番に取り直しています（約__HOF_CYCLE__日で一周）。
縦型のショート動画は載せていません（横長のカードに合わないため）。NEW＝昨日の棚に無かった動画です。
AI音声で読み上げるだけの量産チャンネルは、見つけ次第ランキングから外しています。
今日の棚には殿堂入りの動画を出さないようにしているので、同じ動画が上下に並ぶことはありません。
同じチャンネルばかりが並ばないよう、1つの棚に同じチャンネルは3本までにしています。大きく出るベスト3の枠は、必ず違うチャンネルから選んでいます。
日本で再生できない動画（削除・非公開・地域制限・年齢制限）は載せていません。
動画の再生は YouTube 上で行われます。当サイトは動画を保存・再配信していません。
